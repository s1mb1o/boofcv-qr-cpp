# Security Policy

This is an image-processing library and CLI. Do not run it on untrusted images
inside privileged services without the usual sandboxing, resource limits, and
input-size controls.

## Reporting

For security-sensitive reports, use GitHub's private vulnerability reporting if
it is enabled for the repository. If private reporting is not enabled, open an
issue with a minimal description and request a private contact path before
posting exploit details.
