# v0.1.0 Release Notes

Initial public release candidate for `boofcv-qr-cpp`.

## Highlights

- C++17/OpenCV port of BoofCV's QR detection and decoding pipeline.
- `qr_scan` CLI for single-image and parallel directory scans.
- PyBoof-compatible Python QR subset in the `boofcv_qr` package.
- Python batch scans with `BatchScanConfig`, polygon-only detection, raw
  codeword metadata, and result `as_dict()` helpers.
- BoofCV dataset regression harness with locked Java-baseline comparison.
- Apache-2.0 licensing and upstream attribution.

## Python

The Python API supports GrayU8 / `numpy.uint8` QR detection:

```python
import numpy as np
import boofcv_qr as pb

detector = pb.FactoryFiducial(np.uint8).qrcode()
image = pb.load_single_band("image.png", np.uint8)
detector.detect(image)

for candidate in detector.detect_polygons_only(image):
    print(candidate.version, candidate.bounds.as_list())
```

This is a QR-focused compatibility subset, not a full replacement for PyBoof.

## Packaging Note

macOS wheels are built with `cibuildwheel` and repaired with `delocate`.
Linux wheels are currently native system-OpenCV artifacts, not manylinux
wheels; install compatible OpenCV runtime packages first or build from source.
PyPI publication is intentionally deferred until Linux OpenCV bundling is
settled. See `docs/packaging.md`.
